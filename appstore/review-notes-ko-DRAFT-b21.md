## 2. 차단 조건 해소 후 사용할 기능 설명 초안

Matths는 iPhone과 iPad에서 개념 수업, 문제 풀이, 오답 복습과 공식 평가를 이용하는
고등수학 학습 앱입니다. 학생 화면의 기본 탐색은 **오늘 · 학습 · Arena · 기록 · 나**로
구성됩니다. iPhone은 세로·가로를 지원하며, 가로 풀이 화면에서는 문제와 풀이 메모를
나란히 볼 수 있습니다. 긴 문제지·문항 목록에는 필요한 내부 스크롤을 제공합니다.

### 첫 로그인과 과목 선택

1. App Store Connect 로그인 정보란에 별도로 제공할 전용 심사 계정으로 로그인합니다.
2. 첫 학습 안내가 나타나면 **과목 고르고 시작하기**를 선택해 과목·단원 화면으로
   이동할 수 있습니다. 이는 사용법 안내를 건너뛰는 선택이며 점수·개념 완료를 부여하지 않습니다.
3. 안내가 필요한 경우 **안내를 따라 첫 학습 해보기**를 펼칠 수 있습니다. 목표 선택,
   간단한 확인 두 문항, 개념 한 가지와 확인 문제 세 개로 학습 동선을 안내합니다.
   시작 단계의 두 문항은 공식 점수·진도·배치에 반영되지 않습니다.
4. 앱 사용 안내는 **나 → 프로필과 설정 → 대시보드 튜토리얼 다시 시작**에서 다시
   볼 수 있습니다. 기존 학습 진도·오답을 초기화하는 기능은 아닙니다.

이미 안내를 끝냈거나 건너뛴 계정은 첫 안내가 자동 표시되지 않을 수 있습니다.
이 경우에도 **학습 → 과목과 단원**에서 바로 시작합니다.

### 학습과 평가 확인 순서

1. **오늘**에서 이어서 할 개념·평가·복습을 확인합니다. 최근 7일 학습 시간·푼 문제·
   정답률과 개념 진도도 표시합니다. 연결이 끊겼을 때는 저장된 기록이라는 상태를
   구분하며 재확인 동선을 제공합니다.
2. **학습 → 과목과 단원**에서 공개된 과목의 개념 수업을 엽니다. 설명과 확인·유형
   문제를 이용하며, 과목 공개 여부와 공식 완료 기준은 서버의 정책을 따릅니다.
3. **같은 과목 상세의 단계 평가**에서 소단원 중간평가·대단원 기말평가·과목 종합평가를
   확인합니다. 해제 조건을 충족하지 않은 평가는 남은 조건을 표시합니다. 과목에서
   시작한 평가를 닫으면 그 과목으로 돌아갑니다.
4. **학습 → 평가센터**에서 주간 공식 모의고사·배치고사, 작성하던 평가와 제출 결과를
   확인합니다. 실제 서버 응시 조건·시간·권한에 따라 이용 가능 상태가 달라집니다.
5. **학습 → 짧게 연습**에서 유형 문제를 풉니다. **연습 자료와 풀이 도구**에는
   별도의 오프라인 연습과 시험지 풀이 분석이 있습니다. 오프라인 연습 결과는 공식
   서버 점수·진도를 부여하지 않습니다.
6. **기록**에서 복습 예정 오답, 전체 오답, 개념 학습 기록, 평가 결과와 최근 학습
   리포트를 확인합니다. 과거 기록이 없는 계정에는 빈 상태 안내가 표시됩니다.

### 나: 개인 관리의 여섯 진입점

- 상단 **프로필과 설정** 카드: 프로필·학교·계정 보안·튜토리얼·로그아웃·회원 탈퇴
- **학원과 수업**: 학생의 학원 연결, 출석, 주차별 수업과 과제
- **이용권과 구매 복원**: App Store 상품과 현재 서버 권한, 복원·구독 안내
- **학습 도구와 자료**: AI 코치·자료실·수험관·학습 콘텐츠·커뮤니티·의견함·보호자 센터
- **자주 묻는 질문**
- **문의 내역과 새 문의**

학습 목표 변경과 미완료 첫 학습 이어하기는 해당 상태일 때 이 화면에서 제공합니다.
교사·운영자 계정에는 권한에 맞는 학원 관리 작업공간을 별도로 제공합니다. 학생 계정에
관리자 메뉴가 나타난다고 설명하지 않습니다.

### 학원 기능

학생은 초대 코드 또는 학원 선택과 학습 현황 공유 동의를 거쳐 연결을 요청합니다.
승인·반 배정 후 수업·출석·과제를 확인하며, 교사가 온라인 답안지를 설정한 과제는
앱에서 객관식·단답형 답안을 작성·제출할 수 있습니다. 수정 제출 여부는 서버 마감과
설정에 따릅니다. 교사에게는 반 일정·출결·과제 설정·정답·학생별 결과 관리가 제공됩니다.

### GOAT Arena와 부가 도구

GOAT Arena의 참가 조건, 경기 규칙, 풀이 증거와 결과는 해당 화면에서 확인합니다.
유료 권한·배치·상대 상태가 필요한 동작은 서버가 허용하는 경우에만 진행됩니다.
페이백 계좌 등록은 선택 사항이며 사용자가 확인한 은행·예금주·계좌번호를 서버에 보냅니다.

**학습 도구와 자료**는 AI 코치·자료실·커뮤니티 등 보조 기능의 단일 디렉터리입니다.
보호자 센터는 학생 계정과 별도인 보호자 계정을 사용합니다. AI 모델·콘텐츠 권리 관련
차단 조건이 해결되지 않았다면 관련 기능 설명을 최종 제출 문안으로 확정하지 않습니다.

## 3. 결제 설명 초안 — 실제 검증 후 확정

- `kr.matths.app.pass.29d`: 1개월 자동 갱신, 결제마다 29일 학습 사이클.
- `kr.matths.app.mock.30d`: 주간 공식 모의고사 이용권, 1개월 자동 갱신.
- 실제 구매 버튼의 금액은 App Store의 지역화된 `Product.displayPrice`입니다.
- 서버에서 구매 권한을 확인한 뒤 이용권이 열립니다. 확인 대기·취소·승인 대기를
  성공으로 표시하지 않으며, 앱의 구매 복원 경로로 다시 확인할 수 있습니다.
- 회원 탈퇴와 Apple 구독 해지는 별개입니다. 탈퇴 화면에 구독 관리 링크와 남은
  이용기간·거래가 새 Matths 계정으로 자동 이전되지 않는다는 안내가 있습니다.

이 항목은 코드상 처리 설명입니다. 실제 Sandbox 검증 완료·실판매 가격 확인·상품 심사
승인 사실을 뜻하지 않습니다. 확인 전에는 심사 메모에 그러한 완료 문구를 넣지 않습니다.

## 4. 개인정보·콘텐츠 설명 초안 — 외부 공개 내용과 대조

- 시험지·AI 질문 사진 분석은 기기 내 모델을 사용합니다. 사용자가 별도로 선택한
  프로필 사진·게시판 첨부·시험/풀이 증거 전송과 구분합니다.
- 네이티브 페이백 계좌는 계정과 연결해 서버에 저장되며, 학생 화면에는 저장 후 끝
  4자리만 표시됩니다. Payment Info 공개를 생략하지 않습니다.
- 개인정보처리방침과 이용약관, 문의·회원 탈퇴 경로는 앱 안에서 접근할 수 있습니다.
- 게시판의 신고·차단·게시 전 필터와 관리자 처리 흐름을 최종 운영 서버에서 확인한
  뒤 설명을 확정합니다. 사용자 생성 콘텐츠의 탈퇴 보존 정책은 상단 차단 조건을 먼저 해결합니다.
- 권리 확인 전의 KICE 원문은 내부 DEBUG 자료 게이트 대상입니다. 정식 빌드에서
  제공하지 않는 원문을 심사 계정이 볼 수 있다고 안내하지 않습니다.
