# App Store 제출 자산

이 디렉터리는 App Store Connect에 그대로 올리는 최종 자산과 제출 문안을 보관한다.
기본 스크린샷은 2026-08-31의 build 13 후보 소스를 직접 빌드해 캡처했고,
튜토리얼 2장은 iPad·iPhone 가로 카드 높이 결함을 수정한 build 14 후보 소스에서
같은 가상 학습자와 캡처 조건으로 다시 만들었다. 나머지 화면은 build 14에서
후속 변경의 영향이 없음을 다시 대조해 사용한다.
iPhone 6.9인치와 iPad 13인치 가로를 각각 실제 시뮬레이터 규격으로 검수했고,
예전 탭 표시와 25단계 튜토리얼이 남은 자산은 제출 세트에서 교체했다.

## iPhone 6.9인치 가로 스크린샷

`screenshots-iphone-6.9-landscape/`의 7장은 모두 **2868 × 1320, RGB, 알파 없음**이다.
Apple의 6.9인치 iPhone 가로 스크린샷 허용 규격에 맞는다. iPhone 앱은 가로 사용을
핵심 학습 문맥으로 삼으므로 이 세트를 기본 제출 순서로 사용한다.

| 순서 | 파일 | 화면 | 심사자에게 보여 주는 핵심 |
|---:|---|---|---|
| 1 | `01-home.png` | 홈 | 오늘 복습과 주간 학습 통계를 한 화면에서 확인 |
| 2 | `02-curriculum.png` | 커리큘럼 | 오늘 이어갈 개념과 전체 진도를 좌우로 비교 |
| 3 | `03-quick-practice.png` | 퀵 연습 | 문제는 왼쪽, 풀이 메모와 답은 오른쪽에 고정된 가로 풀이 화면 |
| 4 | `04-wrong-notes.png` | 오답노트 | 오늘 복습 대기열과 검색·필터 |
| 5 | `05-goat-arena.png` | GOAT Arena | 현재 티어와 1대1 수학 경쟁 진입점 |
| 6 | `06-pro-report.png` | 시험지 채점 Pro | 문항별 채점 결과와 틀린 이유 분류 |
| 7 | `07-tutorial.png` | 네이티브 튜토리얼 | 최신 웹 튜토리얼과 동기화된 단계별 앱 안내 |

스크린샷의 `지우`는 Apple 심사용으로 만든 가상 학습자다. 실제 회원의 이름, 학교,
점수나 알림을 사용하지 않는다. 캡처 전용 상태는 DEBUG에서만 컴파일되며 Release
바이너리와 운영 계정 데이터에는 들어가지 않는다. 캡처 화면에는 디버그 바나 테스트
표식이 노출되지 않는다.

검증:

```bash
node scripts/verifyAppStoreAssets.js
node scripts/verifyAppStoreLiveMetadata.js
```

첫 명령은 오프라인 자산 계약이고, 두 번째는 운영 웹의 지원·약관·개인정보처리방침과
Apple 결제 통지 경계가 실제 배포본에서도 열려 있는지 확인한다.

## iPad 13인치 가로 스크린샷

`screenshots-ipad-13-landscape/`의 7장은 모두 **2752 × 2064, RGB, 알파 없음**이다.
iPhone 세트와 같은 순서·가상 학습자 상태를 사용한다. 넓은 화면에서는
커리큘럼 과목 탐색, 풀이 메모와 문항별 채점 설명이 동시에 더 많이 보이도록 구성했다.

`screenshots-13inch-legacy/`는 과거 서버·계정 상태를 기록한 참조본이다. App Store
Connect에는 올리지 않는다.

## 제출 문안

`metadata/ko-KR.json`은 한국어 버전 정보의 단일 원본이다. 앱 이름, 부제, 설명,
키워드, 지원·마케팅·개인정보처리방침 URL과 새 고객센터 메일을 포함한다.

`review-notes-ko.md`는 심사 메모 초안이다. 로그인 뒤 기능을 심사하려면 운영 서버에서
작동하는 전용 심사 계정이 필요하다. 계정 비밀번호는 저장소에 넣지 않고 App Store
Connect의 로그인 정보 칸에만 입력한다.

`app-privacy-ko.md`는 앱 개인정보 설문의 단일 입력 기준이다. 매니페스트와 실제 전송
경로를 대조한 데이터 유형·연결 여부·목적을 그대로 App Store Connect에 입력한다.

`app-store-connect-inputs-ko.md`는 2026-08-31 App Store Connect 실계정에서 확인한
미입력 항목과 두 자동 갱신 구독의 ID·가격·현지화·심사 메모를 모은 입력 기준이다.
실제 청구 가격과 콘텐츠 권한처럼 사업자 판단이 필요한 값은 확인 없이 저장하지 않는다.

`accessibility-ko.md`는 제품 페이지의 손쉬운 사용 선언 기준이다. VoiceOver, 더 큰
텍스트, 다크 모드, 색상 외 구별, 충분한 대비와 동작 줄이기만 실제 코드·기기 증거에
근거해 지원으로 표시하고, 핵심 여정을 끝까지 검증하지 않은 기능은 선택하지 않는다.

`RELEASE_READINESS.md`는 사람이 직접 끝내야 하거나 외부 계정 상태 때문에 자동화할 수
없는 마지막 항목만 남긴다. 완료된 검사 목록을 또 체크리스트로 복제하지 않는다.
