# App Review 메모 — build 16

Matths는 iPhone과 iPad를 지원하는 고등수학 학습 앱입니다. iPhone에서는 세로와 가로를
모두 지원하며, 가로에서는 문제를 왼쪽에, 풀이 메모와 답 입력을 오른쪽에 배치합니다.

## 심사 권장 순서

1. 전용 심사 계정으로 로그인합니다.
2. 최초 진입 안내에서 `새 개념 학습`, `틀린 문제 복습`, `시험 대비` 중 하나를 선택하고
   코치 말투를 정한 뒤 바로 시작합니다. 건너뛰기도 가능합니다.
3. 홈에서 `복습 시작` 또는 `바로 한 문항`을 선택합니다.
4. 커리큘럼에서 공통수학1의 학습 가능한 개념을 엽니다.
5. 오답노트에서 오늘 복습 대기열과 문제별 설명을 확인합니다.
6. `학원·서비스`에서 계정 역할에 맞는 학원 화면과 자료실·스토어·고객지원 화면을 확인합니다.
7. GOAT Arena에서 현재 티어와 경기 규칙을 확인합니다.
8. 시험지 채점 Pro에서 사진 선택, 온디바이스 분석 안내와 결과 화면을 확인합니다.
9. 프로필의 설정에서 이용약관, 개인정보처리방침, 고객지원, 로그아웃과 계정 탈퇴를 확인합니다.

## 게시판 사용자 생성 콘텐츠 안전 기능

- 게시글과 댓글은 게시 전에 고신뢰 욕설·혐오·위해 조장 표현 및 개인 연락처 필터를
  통과해야 합니다.
- 게시글 상세에서 `게시글 신고`를 열어 운영자에게 신고할 수 있고, 게시글 작성자와 각
  댓글 작성자를 같은 화면에서 바로 차단할 수 있습니다.
- 차단하면 두 계정이 서로의 게시글과 댓글을 볼 수 없고 추천·비추천이나 댓글 작성도
  할 수 없습니다. 게시판 상단의 `차단 관리`에서 해제할 수 있습니다.
- 익명 콘텐츠에서 사용자를 차단해도 차단 목록에는 당시 익명 이름만 표시되며 실제
  계정명은 노출하지 않습니다.
- 고객지원 연락처는 아래 기재한 이메일이며, 신고된 콘텐츠는 관리자 화면에서 숨김·삭제,
  경고 및 처리 결과 기록이 가능합니다.

## 심사 계정

- 사용자 이름: App Store Connect의 로그인 정보 칸에만 입력
- 비밀번호: App Store Connect의 로그인 정보 칸에만 입력
- 계정 조건: 이메일 로그인 가능, 공통수학 진도 3개와 복습 예정 오답 3개 포함

이 계정은 유료 권한이 없는 상태로 준비되어 있습니다. 무료 홈·커리큘럼·퀵 연습·
오답노트를 먼저 확인하고, 함께 제출한 자동 갱신 구독을 Sandbox에서 구매하면
배치고사와 GOAT Arena 유료 흐름을 이어서 확인할 수 있습니다. 구매 전부터 배치 결과나
활성 Arena 상태가 있다고 심사 메모에 기재하지 않습니다.

비밀번호나 세션 토큰을 이 파일 또는 Git 기록에 넣지 않습니다. 소셜 로그인만 제공하는
개인 계정이 아니라 심사 기간 동안 유지되는 이메일 전용 계정을 사용해야 합니다.

## 네트워크와 유료 기능

- 운영 API: `https://www.matths.kr`
- 개인정보처리방침: `https://www.matths.kr/privacy`
- 이용약관: `https://www.matths.kr/terms`
- 고객지원: `https://www.matths.kr/faq`, `dltkddbs4553@matths.kr`
- 서버 기반 기능은 심사 기간 내내 운영 상태를 유지합니다.
- Sign in with Apple은 네이티브 앱과 웹 모두 제공하며, 앱 안 계정 탈퇴 시 Apple
  자격 증명 재확인과 토큰 폐기 절차를 수행합니다.
- 인앱결제 상품이 심사 계정에 필요한 경우, App Store Connect에서 함께 제출한 상품과
  Sandbox 환경을 사용합니다. 외부 결제 링크로 디지털 기능을 구매하도록 유도하지 않습니다.

## 개인정보 관련 동작

- 시험지 사진 분석은 기본적으로 기기에서 실행됩니다.
- 프로필 사진 저장이나 풀이 증거 제출을 사용자가 선택한 경우에만 해당 이미지가 Matths
  서버로 전송됩니다. 카메라·사진 접근 전에 시스템 권한 설명이 표시됩니다.
- 프로필 화면에서 앱 안의 계정 탈퇴를 시작할 수 있습니다.
- 이메일 계정은 현재 비밀번호로, Google·Apple·카카오 계정은 각 공급자의 새 본인 확인
  후 앱 안에서 탈퇴할 수 있습니다.
