# App Store Connect 손쉬운 사용 응답 — build 16

이 문서는 App Store Connect의 **앱의 손쉬운 사용** 질문에 옮길 단일 기준이다.
제품 페이지에 공개되는 주장이므로 코드가 일부 대응한다는 이유만으로 체크하지 않고,
Release 경로와 실제 시뮬레이터에서 확인한 항목만 `지원`으로 둔다.

## 지원으로 선택

| 기능 | 응답 | 근거 |
|---|---|---|
| VoiceOver | 지원 | 네이티브 버튼·상태에 의미 라벨을 제공하고 수식은 `MathLabel`의 MathML 접근성 문장으로 읽는다. iPhone 가로 풀이 화면에서 수식 문제와 전체 탭 이름의 읽기를 실기 확인했다. |
| 더 큰 텍스트 | 지원 | 네이티브 글꼴은 Dynamic Type 텍스트 스타일을 사용한다. 교육 WebView 10종과 서버 게시판·Arena WebView는 AX5에서 2.1배 글자/문서 배율과 최대 4배 확대·확대 후 이동을 제공한다. iPad iOS 26.5의 `MATTHS_ACCESSIBILITY_DEVICE_SELFTEST_V1`에서 AX5 계산 글자 33.6pt와 200% 이상 확대가 PASS했고, 852×393 WebKit 창에서 서버형 게시판이 2.1배로 확대·재배치되며 세로·가로 이동을 유지하는 것을 확인했다. |
| 다크 모드 인터페이스 | 지원 | 시스템 색상 모드와 앱 외관 설정을 모두 반영한다. iPhone 가로 홈과 이용권 화면을 다크 모드에서 실제 렌더링해 제목·본문·상태·CTA를 확인했다. |
| 색상 사용 없이 구별 | 지원 | 성공·대기·경고·잠금 상태를 색상만으로 두지 않고 아이콘, 상태명, 배지 문구와 VoiceOver 라벨을 함께 제공한다. |
| 충분한 대비 | 지원 | 본문·보조·경고·성공용 잉크를 면 색과 분리한 토큰으로 사용한다. 작은 경고·성공 문구는 각각 `warningInk`, `successInk`를 사용하며 밝은 카드 기준 5.93:1, 5.51:1이다. 비활성 버튼도 별도 잉크와 면을 쓴다. |
| 동작 줄이기 | 지원 | 시스템 `accessibilityReduceMotion`이 앱의 모션 설정보다 우선한다. SwiftUI 전환·등장, WebView 애니메이션, 영상·음성을 정지하며 iPad 기기 자가검사에서 시스템 설정과 앱 설정 두 경로가 모두 PASS였다. |

기기 증거 원본은 Git에 사용자 데이터 없이 남기는 대신 로컬 `work/`에 보존한다.
현재 기준 보고서는 `work/accessibility-device-selftest-ipad-05b11b1.json`, 다크 모드
렌더는 `work/audit-home-dark-iphone.png`와 `work/audit-commerce-dark-iphone.png`다.

## 현재 선택하지 않음

| 기능 | 이유 |
|---|---|
| 음성 명령 | 표준 네이티브 컨트롤은 동작하지만 교육 WebView와 캔버스를 포함한 핵심 여정을 음성 명령만으로 완주했다는 기기 증거가 아직 없다. |
| 자막 | 개념 내레이션에는 화면 문장이 함께 표시되지만 모든 영상·오디오 콘텐츠의 대화와 관련 사운드가 시간 동기화된 자막이라는 기준까지는 입증하지 않았다. |
| 오디오 설명 | 시각 영상 전체를 설명하는 별도 오디오 트랙을 제공하지 않는다. |

ASC에서 `시작하기`를 누른 뒤 위 여섯 항목만 지원으로 선언한다. 제품 코드나 기기
증거가 바뀌면 이 문서와 선언을 함께 갱신하며, 미검증 항목을 마케팅 목적으로 추가하지
않는다.
