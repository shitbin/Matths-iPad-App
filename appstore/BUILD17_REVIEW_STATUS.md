# Build 17 — 검수 개선본, 아직 미제출

이 폴더의 기존 build 16 심사 메모·개인정보·접근성 응답·스크린샷은 역사적 제출 자료로 보존한다. 현재 build 17의 화면은 오늘/학습/Arena/기록/나와 새 학습 흐름으로 변경됐다. 기존 스크린샷을 새 빌드의 검증 증거로 사용하지 않는다.

Build 17의 코드·테스트 상태는 `../docs/RELEASE_PARITY_VERDICT.md`를 기준으로 확인한다. 실제 Sandbox 구매/갱신/환불, 실기기 입력·접근성, 새 화면의 최종 제출 스크린샷과 App Store Connect 메타데이터 확인을 마친 뒤에 제출한다. 이 문서는 심사 신청이나 승인 기록이 아니다.
