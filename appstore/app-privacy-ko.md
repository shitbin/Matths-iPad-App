# App Store Connect 개인정보 응답 — 출시 준비본

2026-09-08 현재 소스의 네이티브 페이백 계좌 입력 경로를 반영했습니다. 이 문서와
로컬 매니페스트의 수정은 App Store Connect 게시 완료를 의미하지 않습니다.
**다음 제출 전에 기존 공개 답변과 아래 내용을 대조해 게시해야 합니다.**

이 문서는 `Matths/PrivacyInfo.xcprivacy`와 실제 iPhone·iPad 앱 전송 경로를
App Store Connect의 **앱 개인정보** 질문에 옮길 때 사용하는 단일 기준이다.
모든 아래 항목은 사용자 계정에 연결되며, 추적에는 사용하지 않고 앱 기능 제공에만
사용한다.

| App Store Connect 분류 | 선택할 데이터 유형 | 실제 사용 |
|---|---|---|
| 연락처 정보 | 이름, 이메일 주소 | 회원가입, 로그인, 계정 복구 |
| 식별자 | 사용자 ID | 닉네임·서버 계정·StoreKit 권한 연결 |
| 구입 항목 | 구입 내역 | App Store 구매, 복원, 환불과 학습권 부여 |
| 금융 정보 | 결제 정보 | 사용자가 앱에서 등록하는 페이백 지급 은행·예금주·계좌번호 |
| 사용자 콘텐츠 | 사진 또는 비디오 | 사용자가 선택한 프로필 사진과 제출한 시험·풀이 증거 |
| 사용자 콘텐츠 | 게임 플레이 콘텐츠 | GOAT Arena 매칭, 답안, 승패, 티어와 GP |
| 사용자 콘텐츠 | 기타 사용자 콘텐츠 | 학습 답안·풀이, 게시글·댓글·첨부 |
| 사용 데이터 | 제품 상호 작용 | 진도, 정오답, 풀이 시간, 힌트 사용과 시험 응시 |
| 기타 데이터 | 기타 데이터 유형 | 생년월일, 학교·학년과 학적 상태 |

각 유형의 후속 질문에는 다음처럼 답한다.

- 데이터가 사용자 신원에 연결됨: **예**
- 추적 목적으로 사용됨: **아니요**
- 목적: **앱 기능**
- 타사 광고, 개발자 광고·마케팅, 분석, 제품 개인화, 기타 목적: 선택하지 않음

## 페이백 계좌와 App Store 결제수단의 구분

Apple의 결제 정보 분류에는 은행 계좌번호가 포함됩니다. 따라서 App Store 구입의
카드 정보를 Apple만 처리하더라도, Matths 앱에서 별도로 받는 페이백 계좌는 결제
정보로 공개해야 합니다. [Apple 데이터 유형 안내](https://developer.apple.com/app-store/app-privacy-details/)

- 입력 경로: `GOAT Arena → 페이백 계좌`의 `GoatArenaPaybackAccountSheet`.
- 전송 경로: `POST /api/v1/goat-arena/profile/payback-account/confirm`의
  `bankName`, `accountHolderName`, `accountNumber`.
- 수집 목적: 사용자가 요청한 페이백 지급 계좌 연결. 계정에 연결되며 추적에는
  사용하지 않고 앱 기능 목적으로 사용합니다.
- 사용자가 등록을 선택해야 전송됩니다. 계좌 원문은 입력 화면 메모리에 두며,
  저장 후 학생 화면에는 은행명과 끝 4자리만 표시합니다. 서버에서 보관하는
  데이터이므로 앱 로컬 파일에 저장하지 않는다는 이유로 수집 공개를 생략하지 않습니다.
- App Store 구입의 카드 번호·결제수단은 Apple이 처리하며 이 경로로 받지 않습니다.

기존 build 16 문서의 “웹에서만 계좌를 입력하므로 결제 정보를 선택하지 않는다”는
설명은 현재 앱에 적용하지 않습니다. 현재 매니페스트에는 이 항목을
`NSPrivacyCollectedDataTypePaymentInfo`로 선언했습니다.

## 선택하지 않는 항목

- **기기 ID:** 광고 식별자나 `identifierForVendor`를 수집하지 않는다. StoreKit의
  `appAccountToken`은 특정 기기가 아니라 사용자 계정의 구매 권한을 연결하는 사용자
  ID로 분류한다.
- **카카오 네이티브 로그인:** Kakao SDK for iOS 2.29.0의 개인정보 매니페스트는 계정에 연결되는 기타 데이터 유형을 앱 기능 목적으로 선언하며 추적은 하지 않습니다. 해당 SDK와 Alamofire의 매니페스트·라이선스를 함께 포함합니다. 로그인용 카카오 토큰은 Matths 서버의 발급 앱·계정 검증에 사용하며, 토큰 원문을 로그에 남기지 않습니다.
- **위치·연락처·오디오:** 이번 카카오 로그인 연결에서는 해당 권한·API를 요청하지 않습니다. 추가 SDK 데이터 수집에 관한 ASC 응답은 최종 번들의 개인정보 보고서와 대조해야 합니다.

AI 튜터 질문에만 첨부한 사진은 기기의 로컬 AI와 계정별 대화 복구에만 사용하고
Matths 서버로 전송하지 않는다. 사용자가 그 사진을 프로필 사진이나 시험·풀이 증거로
별도 제출한 경우에만 위의 `사진 또는 비디오` 수집에 포함된다.

개인정보처리방침 URL은 `https://www.matths.kr/privacy`를 사용한다. App Store Connect
응답은 이 문서와 매니페스트를 함께 바꾸지 않은 채 임의로 축소하면 안 된다.

## 제출 전 외부 확인

- [ ] App Store Connect의 금융 정보 → 결제 정보 항목을 현재 수집 경로와 대조
- [ ] 사용자 신원 연결: 예 / 추적: 아니요 / 목적: 앱 기능으로 게시
- [ ] 운영 개인정보처리방침의 페이백 계좌 수집·목적·보관 안내와 일치 확인

실제 계좌 입력·조회·지급이나 App Store Connect 수정은 이번 로컬 문서 검토에서
수행하지 않았습니다.
