# 기기·상태 검증 범위

환경: Xcode 26.6 (17F113), SDK 26.5, iOS 26.3 시뮬레이터. UI QA 번들은 `kr.matths.app.uiqa`로 분리했다. llama는 배포 바이너리에서 확인한 db4480b 소스의 arm64-simulator 빌드를 사용했다. GGUF 추론은 실행하지 않았다.

| 항목 | 상태 | 실제 증거와 한계 |
|---|---|---|
| iPhone 17 가로 Today | PASS | 안내/주 행동 2열, 5개 탭, 첫 CTA 전체 표시. 최초 버튼 잘림을 발견하고 수정한 뒤 다시 확인. |
| iPad Pro 13 세로 Today/학습 | PASS | 사이드바, 오늘 주 행동, 전체 과정·평가·연습·나 진입을 실제 조작. |
| 과목 준비 중 | PASS | 실제 메뉴에서 미적분Ⅱ·기하 disabled와 준비 중 표시 확인. 나머지 잠금은 공통 정책·fixture 검사. |
| 오프라인 연습 | PASS | 단원/소단원 선택 표시, 10문항 시작과 문항·선지 렌더링 확인. |
| 오프라인 생성 반복 | PASS | 실제 JavaScriptCore/Swift PaperFactory로 50개 생성 + 1개 범위 누락, 총 51개 통과. 서버 mutation 없음. |
| 공식 평가 메모 세로/가로 | PASS | 문제지·필기판 병렬 표시. 합성 PKDrawing 표시 후 실제 Simulator 회전에도 필기 유지. |
| 합성 필기 저장·재실행 복원 | PASS | seed 없는 재실행 후 동일 파일에서 복원. SHA-256 `5ec3764ee109ef2fff6ae3de3e1357658430c70f556aa1524d353c3cc7f4a276` 전후 일치. |
| AX5 평가 진입 | PASS | 큰 글자에서 단일 문제 흐름과 메모 열기 CTA를 실제 확인. |
| AX5 메모 안내 | PASS | 최초 하단 안내 잘림을 수정한 뒤 재실행. 최종 화면에서 안내 전체와 저장하고 닫기·메모 도구가 모두 보이는 것을 확인. |
| VoiceOver 접근성 문자열 | PASS (부분) | Simulator 접근성 트리에서 잠금·탭·닫기·메모 조작 라벨 확인. 실제 VoiceOver 과업 완료와는 다름. |
| 실제 손가락/Pencil 입력 | NOT_RUN | 자동 조작 도구의 좌표 drag가 `noWindowsAvailable` 오류. 손가락 모드 전환은 확인했으나 입력 성공으로 간주하지 않음. |
| 실제 iPad 11/13 전 방향·Stage Manager | NOT_RUN | 실기 연결·실제 창 변경·포인터·외부 키보드 조합 필요. 크기 하네스는 대체 증거가 아님. |
| 320–1366 전 폭·AX 전 단계·20회 회전 | NOT_RUN | 전체 행렬 전수 완료를 주장하지 않음. |
| Instruments P50/P95·에너지·메모리 | NOT_RUN | 계약 테스트와 컴파일은 성능 측정을 대신하지 않음. |
| GGUF 실제 추론/중단/열·메모리 압력 | NOT_RUN | 기존 AI 계약 테스트와 실제 모델 실행 증거를 구분. |

위 평가 화면은 DEBUG 서버 fixture(짧은 5문항 시각 검증 회차)를 사용했다. 실제 공식 10/20/40문항 서버 응시·제출·만료의 E2E 증거로 사용하지 않는다. 기록에 raw Bearer·비밀번호·JWS·실제 학생 답안은 포함하지 않았다.
