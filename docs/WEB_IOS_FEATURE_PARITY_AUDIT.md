기준:

  표면은 App Review 3.1.1 때문에 웹으로 열지 않고 기존 StoreKit 화면으로 돌린다.

## 정보 구조 결론

하단 탭을 더 늘리지 않는다. 홈은 여전히 "지금 할 공부 하나"가 가장 크게 보이고,
기존 보조 링크의 `이용권과 상점` 자리를 `학원·서비스` 한 문으로 바꾼다. 그 안에서
계정 역할과 사용 목적에 맞는 항목만 먼저 보여 주고, 관리·자료·문의·이용권을 한곳에
모은다. 학생에게 관리자 버튼을 늘어놓지 않으며, 관리자·교사 계정에서만 해당 진입점을
앞으로 올린다.

## 첫 로그인 결론

자동으로 31단계 기능 투어를 재생하지 않는다. 첫 로그인에는 다음 세 가지만 결정한다.

1. 오늘의 목적: 새 개념 / 약점 복습 / 시험 대비
2. 코치 말투: 순한맛 / 매운맛 / 무음
3. 선택한 목적지로 즉시 `공부 시작`

31단계 상세 투어는 프로필의 명시적 재시작으로만 연다. 처음부터 제품 설명을 읽히는
대신 사용자가 원하는 공부를 고르고 바로 행동하게 한다.

## 실제 경로 소유권

- 네이티브 라우팅: `/main`, `/my-learning`, `/curriculum`, `/visual-learning`,
  `/learning-flow`, `/learn/*`, `/quick-practice`, `/wrong-notes*`, `/assessments*`,
  `/private-mock-exams*`, `/integrity/cases*`, `/account/private-mock-restriction*`,
  `/war-of-masters*`, `/notifications*`, `/profile*`, `/nickname-change*`,
  학생용 `/my-academy*`, `/academy/join/*`, 교사용 주차 수업·과제와 출결.
- Arena 보호 브리지: `/goat-arena*`. 경기·추가 소명 화면에는 기존 캡처 보호를 유지한다.
- 역할 기반 포털: 교사의 통계·포렌식·학원 프로필 등 전체 관리 `/academy*`, 운영자 `/admin*`, `/archive*`, `/store*`,
  `/coach-suggestions*`, `/contact*`, `/faq*`, `/parent*`.
- 웹 결제 차단: `/pricing*`, `/checkout*`, `/payments*`, `/parent/pricing*`,
  `/parent/checkout*`, `/parent/payments*`, `/app/commerce*`. 같은 호스트 내부 링크와
  알림·유니버설 링크 어느 쪽에서도 네이티브 StoreKit으로 돌린다.

포털은 앱 Bearer 토큰을 URL에 붙이지 않는다. 서버가 발급한 단기 일회용 핸드오프를
한 번 소비해 서버 세션 쿠키를 만들고, 그 뒤 지정된 내부 경로를 연다. 외부 호스트는
앱 내부 웹뷰에서 계속 탐색하지 않고 Safari 시트로 격리한다.

## 검증 기록

- iPhone 17 시뮬레이터(iOS 26.3.1) Debug arm64 전체 빌드 통과.
- iPhone 가로 실측: 첫 설정의 세 목적·코치 선택·시작/건너뛰기가 스크롤 없이 한 화면.
- iPhone 가로 실측: 학원·서비스의 역할별 주 기능과 나머지 7개 목적지가 한 화면.
- iPhone 가로 실측: 학생 학원 요약·출석은 왼쪽, 주차별 수업·자료는 오른쪽 2열로 표시.
- 학생 학원 Bearer API 계약과 네이티브 라우팅 계약 통과, Debug arm64 앱 번들 생성 통과.
- 교사 학원 승인·반 배정·출결·초대 Bearer API와 가로 2열 작업대 실측 통과.
- 교사 출결은 iPhone 667×375·852×393 가로, iPad 1024×768, 다크 모드,
  접근성 최대 글자 크기, 정상·빈 반·오류/재시도 상태를 데모 전송계층에서 검증했다.
- 출결 GET 쿼리 이스케이프 오류와 담당 반이 없는 일반 교사의 학원 전체 출결 접근
  가능성을 차단했고, `academy-portal:verify`의 실제 MongoDB 회귀 검증을 통과했다.
- 교사 주차 과제는 반 선택, 수업 요약, 교육과정 개념 검색·최대 30개 선택, 마감일,
  첨부 최대 10개, 파일 미리보기·삭제, 주차 수정·삭제를 네이티브로 구현했다. iPhone
  가로·다크 모드·접근성 큰 글씨, multipart 데모 전송, 전체 학원 포털 회귀 검증을 통과했다.
- 원장용 선생님 탭에서 참여 요청 승인·거절과 활성 선생님 권한 해제를 네이티브로
  처리한다. 일반 교사에는 명단만 보이고 변경 버튼은 숨겨 서버의 OWNER 권한과 일치시켰다.
- 반 탭에서 반 생성, 요일·시작/종료·적용일, 직접 출결/학생 코드와 지각·마감 정책,
  원장 전용 보관·복구를 처리한다. 일반 교사는 담당 반에만 수정 버튼이 표시된다.
- 반별 담임 이전, 현재 담임의 공동 담당 유지 여부, 공동 담당 추가·해제까지 앱에서
  처리하며 담임 이전은 원장에게만 표시하고 실행 전 영향 확인을 한 번 더 받는다.
- 승인된 학생은 반 배정·미배정뿐 아니라 이름을 명시한 확인창을 거쳐 학원 명단에서
  제외할 수 있으며, 제외 즉시 수업·과제 접근이 끊긴다는 영향을 사전에 안내한다.
- 학생 명단은 대시보드의 50명 절단 배열을 쓰지 않고 웹과 같은 20명 페이지형 API를
  사용한다. 현재 페이지 검색·전체 선택, 최대 20명 반 배정/해제/소속 해제, 학생별 월간
  학습 카드·강점·보완·병목·개념 근거·학부모 공유 요약을 네이티브로 처리한다. iPhone
  가로에서는 중복 학원 요약 열을 숨기고 명단과 상세를 좌우 2열로 고정해 각각 스크롤한다.
- `tests/run-*.sh` 전체 99개 연속 실행 통과. 결제·알림·웹뷰·접근성·범용
  레이아웃·가로 풀이·동기화·개인정보·로컬 AI·출시 증거 계약을 포함한다.
