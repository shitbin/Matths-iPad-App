# 학습 흐름과 화면 변경

학생의 기본 목적지를 **오늘·학습·Arena·기록·나**로 구성했다. 이전 커리큘럼·평가·오답·게시판 route는 그대로 열 수 있고 새 목적지에 대응한다. `matths.productFlow.v2.enabled=false`를 설정하고 다시 실행하면 이전 셸을 사용할 수 있다. 공개 과목·공식 평가 정합성 수정은 이 UI flag와 독립적으로 유지된다.

| 화면 | 변경 |
|---|---|
| 오늘 | 실제 진행 중 평가·출석 확인·복습·공식 다음 개념 중 주 행동 하나. 이유와 예상 시간이 있는 경우 함께 표시. 짧은 가로 화면은 안내와 주 행동을 나란히 배치. |
| 학습 | 이어서 수업, 전체 과정, 공식 평가, 짧은 연습, 별도 오프라인 연습. 주간 모의·배치·기출·풀이 분석은 펼치는 보조 구역. |
| 기록 | 오늘 복습을 먼저 제시하고 전체 오답·개념 기록·공식 평가·주간 리포트로 연결. |
| 나 | 프로필/보안, 목표 변경, 학원, 알림, AI 대화, 커뮤니티, 자료실, 수험관, 구매 복원, 지원. |
| 넓은 창 | 컨테이너 폭에 맞는 공통 사이드바. 큰 글자는 하단 탐색으로 복귀. |
| 교사/관리자 | 서버 역할이 허용한 수업/운영 작업공간을 명시적으로 선택. 학원 작업 진입 때 해당 공간으로 전환. |
| 탐색 바 | 일반 스크롤 중 자동 숨김 제거. 시험 작업 중에는 기존 독립 작업 모드 유지. |
| 첫 실행 | 선택적 30초 함수 체험, 목표 하나, 피드백, 공개 과목의 실제 수업 연결. 체험은 demo namespace. 단계·목표 보관, 건너뛰기와 나중에 계속 지원. |
| 비밀번호 | 프로필에서 기존 이메일 인증형 재설정 진입. 실제 Web의 영문·숫자 및 길이 규칙, 확인 입력, 72바이트 상한. |
| 문제 작업대 | 일반 풀이·퀵 연습·공식 평가·Arena·기출·주간 모의가 공통 2열 배치 사용. AX 글자는 단일 흐름/별도 메모. |
| 공식 평가 메모 | 평가별 자동 저장·실행 취소·나가기 flush. 서버 답안으로 자동 전송하지 않음. |

기존 학원·관리자·커뮤니티·자료실 등 기능과 서버 라우트는 유지했다. 단순 한글 연습 문항에는 네이티브 텍스트를 사용해 불필요한 WebView 생성과 빈 로딩 구간을 줄였다. 튜토리얼의 380ms 추측 대기는 실제 애니메이션 완료 신호로 교체했다.

실제 VoiceOver 제스처·Pencil·Stage Manager·성능 P50/P95는 별도 기기 증거가 필요하다. 구조 변경이나 시뮬레이터 화면만으로 모두 통과했다고 주장하지 않는다.
