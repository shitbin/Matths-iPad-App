## 남은 외부 검증·한계

1. 운영 서버 배포, 필요한 새 인덱스의 실제 준비, 조건부 출결의 replica set/트랜잭션 지원 및 운영 smoke. 현재 로컬 검증은 이 작업을 대신하지 않습니다.
2. 실제 StoreKit Sandbox 거래, 두 실제 Matths 계정 사이 구매 귀속·복원·만료·환불 및 배포 번들 Apple 로그인/이메일 중계.
3. 상업 사용 가능한 비전 모델 조건과 충분한 판독 품질. 현재 3B의 별도 계약 확인이 필요합니다.
4. 사용자 요청으로 미실시한 실기 성능·Pencil 입력. 전 화면 VoiceOver·큰 글자·고대비·키보드·포인터는 최하위 우선순위로 유보합니다.
5. 과제 GET→POST는 모든 파일·지시문 변경까지 하나의 원자적 CAS로 묶이지 않습니다. 알려진 OMR 구성 버전 차이는 자동 완료하지 않지만 전체 문제지 원자성 보장으로 표현하지 않습니다.
6. 권한 재검사와 모든 이미 시작된 정본 쓰기를 단일 트랜잭션으로 취소하는 것은 다릅니다. 평가 결과와 후속 오답 반영도 완전한 outbox가 아닙니다.
7. 공인 국가 시험 일정의 공식 서버 계약이 없으므로 임의 날짜를 생성하지 않습니다.
