# Matths iPad 앱 — Claude 인수인계서

기준일: 2026-08-11  
대상: 이상윤 및 후속 Claude 작업자  
패키지 성격: 로컬 작업 스냅샷. GitHub 원본·운영 DB·배포 환경을 수정하지 않은 상태

## 0. 가장 먼저 알아야 할 것

이 패키지는 `Matths.xcodeproj`를 중심으로 한 iPad 전용 SwiftUI 앱 전체 소스입니다.
빌드 캐시와 개인 인증정보만 제외했으며, 소스 검토와 Debug 빌드에 필요한
`Frameworks/llama.xcframework`, 앱 에셋, 내장 웹 강의, 테스트를 포함합니다.

현재 소스의 큰 기능 축은 다음과 같습니다.

- 이메일 회원가입·로그인과 Bearer API 연동
- 13과목·220개념 커리큘럼, 개념 강의, 개념 확인 연습, 평가센터
- 문제 풀이, Apple Pencil 캔버스, 오답노트, 퀵 연습
- GOAT Arena의 Unranked/Ranked 화면, 룰북, 상점, 경기 신청·초대, 순차 5문항 경기
- 주간 공식 모의고사 클라이언트, KICE 내부 검증용 기출 뱅크
- 온디바이스 사진 판독·풀이 채점·튜터·부정행위 shadow review
- iPad Split View, 접근성 글자 크기, Reduce Motion, 웹 콘텐츠 확대

단, 정식 서버 도메인과 Apple 서명은 외부 준비가 필요합니다. 현재
`Matths/ServerAPI.swift`의 기본 주소는 `https://www.matths.kr` 운영 도메인이며 Release 빌드
단계가 이 주소를 발견하면 의도적으로 실패합니다. 이 게이트를 지우거나 우회하지 말고
정식 HTTPS 도메인을 넣어야 합니다.

## 1. 절대 규칙

1. GitHub 원본 레포에 commit/push하지 말 것. 사용자 승인 전까지 로컬 작업만 한다.
2. GOAT Arena 확정 로직을 임의 변경하지 말 것. 앱은 서버 정본을 표시하는 클라이언트다.
3. 운영 Atlas/실사용 계정에 쓰기 실험하지 말 것.
4. `ServerAPI.defaultURL`에 localhost, 사설 IP, ngrok, trycloudflare를 넣은 채 Release하지
   말 것. `verify-release.sh`와 Xcode Release 게이트를 유지한다.
5. KICE PDF를 정식 배포 번들에 넣지 말 것. 사용 허락이 확인되기 전에는 Debug 내부
   검증 자료다.
6. 로컬 AI 판정만으로 학생을 자동 제재하거나 Arena 정산을 변경하지 말 것. 현재
   부정행위 감지는 `shadow review`이며 운영자 검토 보조 신호다.
7. iPadOS가 허용하는 짧은 background task를 무제한 백그라운드 추론처럼 표현하지 말 것.

기본 저메모리 경로는 Qwen2.5-VL 3B로 사진을 판독한 뒤 모델을 내리고 DeepSeek-R1
Distill Qwen 7B로 수학 추론하는 순차 구조다. 두 모델을 동시에 상주시켜 8GB iPad가
종료되는 문제를 피한다. GGUF 파일 자체는 ZIP에 없다.

## 5. 빌드와 실행

### 요구 사항

- macOS + 정식 Xcode
- iPadOS 17 이상 SDK
- 실제 설치 시 Apple ID/Developer Team, 연결 iPad 개발자 모드
- 최초 로컬 AI 사용 시 수 GB 모델 다운로드를 위한 저장 공간·네트워크

### Debug 실행

1. `Matths.xcodeproj`를 연다.
2. Matths 타깃 → Signing & Capabilities에서 본인 Team을 고른다.
3. 필요하면 개인 번들 ID로 바꾼다.
4. iPad 또는 iPad 시뮬레이터를 선택하고 Debug로 실행한다.

`Frameworks/llama.xcframework`가 없으면 로컬 AI bridge가 링크되지 않는다. 전달 ZIP에는
포함돼 있다.

### 정식 서버 주소

```bash
./set-server-url.sh https://api.example.com
```

스크립트는 HTTPS, 끝 슬래시, `/api` 중복, 임시 호스트를 검사한다. 현재 임시
trycloudflare 같은 임시 주소로 되돌아가면 Release가 실패하는 것이 정상이다. 현재 운영 기본값은 `https://www.matths.kr`이다.

### 계약 검사

```bash
for test in tests/run-*.sh; do bash "$test"; done
```

패키징 직전 마지막으로 완료돼 있던 증거:

- iPad `tests/run-*.sh` 10종 통과
- unsigned generic iOS Device Debug 빌드 성공
- 13과목·220개념 커버리지 통과
- 개인정보/Debug-only KICE/WebView 접근성/브랜드/동기화 계약 통과

사용자가 검증을 중단하고 전달 패키지를 우선하라고 지시했으므로, 그 뒤 작업 중이던 웹
주간 모의고사 adapter까지 포함한 전체 서버 통합 검증은 이 패키징 과정에서 재개하지 않았다.

## 6. 서버 계약

앱은 서버 루트 뒤에 `/api/v1/*`를 붙인다. 토큰은 Keychain에 두고 Bearer로 보낸다.
주요 경로군:

- `/api/v1/auth/*`, `/api/v1/me`
- `/api/v1/learning/progress`, `/api/v1/dashboard/activity`
- `/api/v1/placement-exam/*`, `/api/v1/quick-practice/*`, `/api/v1/wrong-notes/*`
- `/api/v1/goat-arena/*`
- `/api/v1/weekly-mock-exams/*`

GOAT Arena와 주간 모의고사에서 서버는 시간, 자격, 경기 상태, 정산, 채점을 최종 판정한다.
클라이언트 값으로 정산 규칙을 복제하거나 우회하지 말 것.

랭킹 공개 이름은 현재 닉네임 전용이다. iPad UI는 실명 선택을 제거했고, 구형 클라이언트
호환 PATCH가 필요한 경우에도 서버는 `nickname`만 허용해야 한다.

## 7. 로컬 데이터와 개인정보

- 계정별 파일은 `DataScope` 슬롯으로 분리한다.
- 인증 토큰은 ZIP에 없고 런타임 Keychain에만 저장한다.
- 채점용 원본 사진은 보호된 임시 파일로 쓰고 완료·실패·취소 때 제거한다.
- 강제 종료로 남은 임시 사진은 다음 실행에서 24시간이 지나면 정리한다.
- 부정행위 shadow review 축소본은 최근 30일·30건으로 제한한다.
- 사진 권한 문구와 `PrivacyInfo.xcprivacy`는 소명 사진의 서버 업로드 사실을 반영한다.

## 8. 현재 남은 외부 게이트와 알려진 한계

### 출시 전 필수

1. 정식 HTTPS API 도메인 연결 및 `ServerAPI.defaultURL` 교체
2. Apple Developer Team/프로비저닝과 실제 iPad 설치 확인
3. 주간 공식 모의고사 Bearer API 전 경로의 서버 배포·실계정 검증
4. PG 연결이 필요한 결제 기능은 별도 서버/정책 범위에서 완성
5. KICE 원문 사용 허락 또는 Release 원격 공급 구조 확정
6. App Store 개인정보 처리방침 공개 URL·심사 계정 준비

### 제품 제약

- iPadOS는 장시간 백그라운드 LLM 추론을 보장하지 않는다. 현재는 가능한 유예 시간 동안
  진행하고 포그라운드 복귀 후 이어가는 구조다.
- 모델 다운로드 용량이 크다. 8GB급 iPad는 VL 3B와 추론 7B를 순차 로드한다.
- 로컬 AI 결과는 보조 판정이다. 자동 징계·정산 변경은 금지한다.
- KICE PDF는 Debug에서만 복사되며 Release 혼입 시 빌드가 실패한다.
